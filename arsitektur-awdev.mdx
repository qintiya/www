Domain produksi yang dituju adalah **https://awdev.eu.org**. Ini adalah spesifikasi implementasi. Jumlah aset, artikel, dan URL terindeks adalah target, bukan laporan produksi.

## Struktur proyek

Usulan stack: Next.js App Router dan TypeScript, CMS untuk konten editorial, serta penyimpanan objek dan CDN untuk media. Sajikan HTML dari server atau hasil build. Muat kode interaktif hanya di halaman yang memerlukannya.

```text
src/
  app/              # Rute, layout global, metadata, sitemap
  modules/          # web-development, tools, islam, gallery, learning, partners, blog
  components/       # Navigasi, breadcrumb, formulir, kartu
  lib/              # URL kanonis, validasi, persetujuan
  adapters/         # CMS, penyimpanan media, penyedia data
public/             # Identitas dan berkas akar domain
scripts/            # Audit URL, tautan, skema, dan aset
tests/              # Uji unit, aksesibilitas, dan alur pengguna
```

Rute meminta data melalui modul, bukan langsung ke CMS. Modul memvalidasi data sebelum komponen merender halaman. Ketika artikel berubah, perbarui cache artikel, kategori terkait, dan sitemap tanpa membangun ulang seluruh katalog.

## Modul, rute, dan data

| Modul | Rute yang direncanakan | Kontrak halaman |
| :--- | :--- | :--- |
| Web development | `/web-development/[slug]` | Layanan atau studi kasus: masalah, pendekatan, hasil, kontak. |
| Free online tools | `/tools/developer/[slug]`, `/tools/utility/[slug]` | Setiap alat memiliki skema input, contoh, dan hasil yang bisa diuji. Proses input lokal bila memungkinkan. |
| Islamic tools | `/islam/[slug]` | Cantumkan metode, satuan, dan sumber. Untuk jadwal salat, sediakan pilihan kota manual jika izin lokasi ditolak. |
| Galeri | `/galeri/gambar/[slug]`, `/galeri/video/[slug]` | Simpan ID unik, dimensi, kredit, dan lisensi per aset. Sediakan teks alternatif untuk gambar serta poster dan takarir untuk video dengan dialog. |
| E-learning dan mitra | `/belajar/[kursus]/[pelajaran]`, `/mitra/[slug]` | Urutkan pelajaran dalam kursus. Tautkan mitra ke kursus atau proyek terkait dan sebaliknya. |
| Blog | `/blog/[kategori]`, `/blog/[kategori]/[slug]` | Satu kategori utama per artikel, slug unik, penulis, rujukan, tanggal, dan status publikasi. |

Sediakan indeks setiap modul dan tautan HTML ke halaman detail. Alur editorial: **draf → tinjauan → terbit → pembaruan**. Lindungi pratinjau nonpublik dengan autentikasi. Untuk materi Islam, catat sumber dan peninjau, serta jelaskan batas penggunaan hasil perhitungan.

## Kriteria rilis

- **Responsif:** uji lebar 320 piksel, zoom 200%, dan navigasi keyboard. Saat lightbox ditutup, kembalikan fokus ke thumbnail asal.
- **Core Web Vitals:** target persentil ke-75 untuk seluler dan desktop adalah LCP ≤ 2,5 detik, INP ≤ 200 milidetik, dan CLS ≤ 0,1. Uji sebelum rilis dengan iklan aktif dan ukur data lapangan setelah trafik mencukupi.
- **Media:** tentukan dimensi, `srcset`, dan `sizes`. Prioritaskan gambar LCP, tunda gambar di luar layar, sediakan ruang slot iklan, dan muat pemutar video setelah interaksi. Hitung 30 gambar dan 30 video berdasarkan ID unik.
- **Alat:** uji input kosong, nilai batas, format salah, dan hasil diketahui. Untuk jadwal salat, variasikan kota, zona waktu, tanggal, dan metode.
- **SEO:** uji status 200 untuk konten terbit, pengalihan permanen untuk perubahan slug, dan 404 untuk URL yang tidak ada. Gunakan `Article`, `BreadcrumbList`, atau `VideoObject` sesuai konten terlihat.
- **Indeksasi:** hitung artikel terbit, URL artikel dalam sitemap, dan URL terindeks di Search Console secara terpisah. Publikasi 900 artikel tidak menjamin 900 URL terindeks.
